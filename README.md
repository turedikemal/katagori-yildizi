# Kategori Yıldızı - ikas App Store Uygulaması

Bu uygulama, ikas mağazalarının sipariş verilerini GraphQL API üzerinden otomatik olarak analiz ederek her kategorideki en çok satan 1., 2. ve 3. ürünleri hesaplar.

## Özellikler
- **Otomatik OAuth ve GraphQL Entegrasyonu:** Mağaza siparişlerini tarar ve kategori bazlı çok satanları listeler.
- **Storefront Widget:** Ürün kartlarında koyu yeşil şerit ve ürün detay sayfasında oval gradyanlı rozet gösterimi.
- **Yönetim Paneli:** Rozet renk ve limit ayarlarının yapıldığı sade admin arayüzü.
